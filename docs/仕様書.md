# AltBridge

## 概要

### 目的
元のドキュメントを一切変更せずに、Web上の画像に対してAIによる補助的な説明（代替テキスト案）を生成する。

### やらないこと（Non-goals）
- 既存のalt属性を置き換える
- ページのHTML/DOMを書き換える
- デフォルトで画像を外部にアップロードする
- CSSのbackground-imageを解析対象にする（将来検討）

---

## 設計原則

1. **altもDOMも変更しない**
   alt属性・HTML構造は一切書き換えない。AI生成結果は拡張機能内（ポップアップ/オーバーレイ）でのみ保持・表示する。「サイトの意味を勝手に変えない」という安心感を最優先する。

2. **画像は外部送信しない（ローカルファースト）**
   デフォルトはローカル推論のみ。クラウドプロバイダはオプトインの上級者向け機能とし、MVPのスコープには含めない。理由：
   - 画像の著作権者の意図しない二次利用・第三者送信になりうる
   - サードパーティAPI規約上、送信データの学習利用可否が不透明なケースがある
   - 個人利用の私的複製の範囲を超える可能性がある

3. **モデルはユーザーが自由に選択・差し替え可能**
   拡張機能はモデルの性能・種類を前提にしない。`CaptionProvider`インターフェースを介して疎結合にし、高スペック環境では高精度モデル、低スペック環境（共有VRAM/CPU推論）では軽量モデルを選べるようにする。

---

## 対象画像の検出

### 検出対象
- `img`要素
- 遅延読み込み画像（lazy-loaded）
- 動的に挿入される画像（MutationObserver等で検知）

### 解析候補（alt品質が疑わしいもの）
- altが存在しない → 「説明が必要かもしれない」として警告扱い
- alt文字列が機械的に「怪しい」パターンに該当するもの
  - ファイル名らしき文字列（例: `IMG_1234`, `image`, `photo`, 拡張子付き文字列）
  - 汎用語のみ（例: `画像`, `写真`）
  - URLそのもの
  - 極端に短い（目安: 3文字未満）
- 上記以外の「意味的な怪しさ」（内容と合っているか等）はAIによるalt評価機能に委ねる

#### `alt=""`（空alt）の扱いについて
`alt=""`は仕様上「装飾目的で意図的に読み上げを省略している」という正しい実装であるケースと、「本来説明すべきなのにさぼった」ケースの両方があり、機械的に区別できない。`role="presentation"`/`aria-hidden="true"`が併記されていれば装飾目的と確定できるが、実際にはこれらのARIA属性を付けずに`alt=""`単体で装飾を表現する実装が大半のため、確定判定に頼れない。

そのため`alt=""`は「altなし」と同列の警告には分類せず、**中間カテゴリ（装飾の可能性あり）** として扱う。

判断の補助シグナル（確定はできないが分類の参考にする）:
- 画像サイズが小さいか
- 近傍のテキストコンテンツの有無（装飾画像は近くに同内容を伝えるテキストがあることが多い）
- `figure`/`figcaption`の有無
- リンク/ボタン要素内の画像か（機能的な画像は装飾より意味を持つ傾向）

### 除外対象
- 極小アイコン（目安: 16×16px以下）
- data URIの小さい画像
- SVGアイコン
- favicon
- `role="presentation"` または `aria-hidden="true"` が指定された画像（装飾目的として意図的にalt省略されているため対象外）
- CSS background-image（MVPでは対象外）

## 機能

### 1. キャプション生成（画像説明）
- ローカル推論によるオンデマンド生成（自動生成はデフォルトOFF。クリック等の明示的操作をトリガーとする）
- プロンプトは固定＋カスタマイズ可能
  - デフォルトプロンプト例:
    > この画像を視覚障害者向けに説明してください。推測は避け、見えている内容を中心に100文字以内で説明してください。不確実な場合は「〜と思われます」と表現してください。

### 2. alt評価機能
既存のalt属性の品質をAIが評価し、改善案を提示する。Web開発者向けのアクセシビリティ支援ツールとしても機能する。

表示イメージ:
```
alt: "画像"

評価: ★★☆☆☆
理由: 画像の内容が伝わりません。

AI改善案: 「夕暮れの海岸で犬が走っている写真」
```

### 3. （将来）拡張機能
- OCR
- グラフ専用の説明
- 数式の説明
- ミームの説明
- UIスクリーンショットの説明

## UI

### ブラウザアクションのポップアップ（メイン）
ページ内の画像を分類して一覧表示する。

```
このページ

⚠ altなし（説明が必要かもしれません）
・画像1
    [AI説明を生成]

❔ alt=""（装飾目的かもしれません）
・画像2
    [念のため確認する]

✓ altあり
・画像3

⚠ altが不適切かもしれません
・画像4
```

`alt=""`は一律で警告扱いにしない。装飾目的の正しい実装である可能性が高いため、ノイズの少ない中間カテゴリとして分離し、必要な場合のみユーザーが確認できるようにする。

画像をクリックすると詳細を表示:
```
AIによる画像説明
「赤い自転車が...」

信頼度: 中程度の確信 ※confidenceに応じて表現を変える（下記参照）
```

### コンテキストメニュー
右クリックから個別画像に対して「AI説明を生成」を呼び出せるようにする。

### オーバーレイ（オプション）
画像近くに直接表示する方式。デフォルトはOFFとし、ポップアップ中心の設計とする（ページ上への視覚的な干渉を避けるため）。

---

## confidenceの扱い

APIレスポンスの`confidence`はUI表示に反映する。数値をそのまま出すのではなく、段階的な文言に変換して提示する。

| confidence目安 | UI表現 |
|---|---|
| 高 | 「AIによる説明」 |
| 中 | 「AIによる説明（不確かな部分があります）」 |
| 低 | 「AIがうまく認識できませんでした。参考程度にご覧ください」 |

低confidence時に生成自体を抑制するかどうかは、閾値をSettingsで調整可能にする（デフォルト閾値は実装時にモデル特性を見て決定）。

## Provider API

### インターフェース

```typescript
interface CaptionProvider {
  caption(request: CaptionRequest): Promise<CaptionResponse>;
}

interface CaptionRequest {
  image: Blob | ArrayBuffer;   // 画像データ
  prompt?: string;             // カスタムプロンプト（省略時はデフォルトプロンプト）
  maxSize?: number;            // 送信前にリサイズする最大辺（px）
}

interface CaptionResponse {
  caption: string;
  confidence: number;   // 0.0〜1.0
  model?: string;        // 使用モデル名（デバッグ・UI表示用、任意）
}
```

### エンドポイント仕様（ローカル推論サーバーの実装契約）

```
POST /caption
Content-Type: multipart/form-data

フィールド:
  image: 画像ファイル

レスポンス:
{
  "caption": "...",
  "confidence": 0.82
}
```

裏側のモデル（Gemma / LLaVA / Qwen2.5-VL 等）は自由に差し替え可能。拡張機能側はこのインターフェースにのみ依存する。

### 推奨構成（参考プリセット）
セットアップの敷居を下げるため、環境別の推奨モデルをドキュメントで提示する。

| 環境 | 推奨モデル（目安） |
|---|---|
| 共有VRAM/CPU推論 | 軽量モデル（1B〜2Bクラス、または専用キャプショニングモデル） |
| 一般的なノートPC（GPU搭載） | 4Bクラス（例: Gemma 3 4B） |
| デスクトップ高VRAM環境 | 高精度モデル（例: Gemma 27B、Qwen2.5-VL等） |

※キャプション生成とalt評価で要求される能力が異なるため、機能ごとに異なるモデル（プロバイダ）を割り当てられるようにしてもよい。

---

## 設定（Settings）

- **プロバイダ選択**: ローカル推論サーバーのエンドポイント指定。将来的にクラウドプロバイダを追加する場合もここで選択（デフォルトはローカルのみ）
- **プロンプトのカスタマイズ**: デフォルトプロンプトの上書き
- **最大画像サイズ**: 送信前リサイズの上限（負荷軽減）
- **自動生成ポリシー**: デフォルトはオンデマンド（クリック時のみ生成）。ページ読み込み時の自動一括生成はオプトインとし、デフォルトOFF
- **confidence表示閾値**: 低confidence時の表現切り替えライン

---

## プライバシー

ローカルファースト。ユーザーが明示的にクラウドプロバイダを有効化しない限り、画像は一切アップロードされない。

---

## アクセシビリティ

AI生成キャプションはあくまで補助情報である。元のアクセシビリティメタデータ（alt属性等）は常に保持され、拡張機能によって上書き・削除されることはない。

---

## ローカルAIサーバー未検出時の挙動

拡張機能初回起動時、または`/caption`エンドポイントへの疎通確認に失敗した場合:
- 該当機能（キャプション生成・alt評価）のUIは無効化またはグレーアウト表示にする（エラーを強く出しすぎない）
- セットアップガイドへの導線を表示する
- 迷った場合の推奨構成（上記プリセット表）を提示する
