# AltBridge

AltBridge は、WebページのDOMや既存の `alt` 属性を変更することなく、必要に応じてAIによる画像説明を生成するChrome拡張機能です。

## 概要

- ページ上の画像を検出し、`alt` 属性の状態を分類します（ページ自体は変更しません）。
- AIによる画像説明は、ユーザーが明示的に実行した場合のみ生成されます。
- デフォルトでは設定可能なローカル Ollama プロキシを利用します。
- 英語・日本語のUIおよびプロンプトプリセットをサポートしています。
- 生成結果は、画像・エンドポイント・モデル・プロンプト・画像サイズ設定ごとに個別に管理されます。

## クイックスタート

必要環境:

- Node.js 22 以上
- Ollama
- Vision対応モデル

```bash
npm install
ollama pull gemma3:4b
npm run ollama-proxy
```

別のターミナルで拡張機能をビルドし、Chrome または Microsoft Edge のデベロッパーモードから `dist` ディレクトリを「パッケージ化されていない拡張機能」として読み込んでください。

```bash
npm run build
```

デフォルトの接続先は `http://127.0.0.1:8788` です。

モデル欄を空欄にすると、プロキシ側のデフォルトモデル (`gemma3:4b`) が利用されます。

## 開発

```bash
npm test
npm run mock-server
```

モックサーバーは `http://127.0.0.1:8787` で起動します。

開発時のみ利用できる `X-Mock-Confidence` ヘッダーに対応しています。

## セキュリティとプライバシー

画像は、ユーザーが **「AIによる説明を生成」** を実行した場合にのみ送信されます。

デフォルトのプロキシは `127.0.0.1` のみにバインドされ、リリースビルドではデバッグ目的で画像を保存・公開することはありません。

LANサーバーはローカルネットワーク内であっても、画像が別のデバイスへ送信されるため、新たなプライバシー境界となります。

AltBridgeでは、ループバック以外のエンドポイントを利用する場合、明示的なユーザー同意とアクセストークンを必須としています。

アクセストークンはブラウザのローカルストレージに保存され、同期ストレージには保存されません。

## AI活用について

AltBridge の開発では、GPT/Codex 系ツールを活用し、開発効率の向上を図りました。

- **アーキテクチャ設計**  
  拡張機能と推論バックエンドを分離する「ローカルファースト」構成の検討・設計支援にAIを活用しました。
- **スキャフォールディング**  
  Chrome Extension のマニフェスト、React コンポーネント、および Node.js / Express サーバーの雛形生成に活用しました。
- **デバッグ・リファクタリング**  
  `multipart/form-data` のバッファ解析に関する不具合の調査や、国際化（i18n）対応に伴うリファクタリング支援に活用しました。

最終的な設計判断、実装、レビュー、および品質管理は開発者自身が行っています。
